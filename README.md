# Criador de Sites

Landing page institucional simples e rápida, criada com HTML, CSS e JavaScript sem dependências pesadas.

## Visão geral

Este projeto foi desenvolvido como uma landing page leve e responsiva para um negócio de criação de sites, com foco em:
- conversão por WhatsApp
- leitura rápida em mobile
- acessibilidade básica
- SEO técnico simples
- pouca dependência de bibliotecas

## Estrutura

- `index.html` — página principal
- `styles.css` — design tokens e layout responsivo
- `script.js` — menu mobile e atualização do ano do footer
- `robots.txt` — regra de indexação
- `sitemap.xml` — mapa do site
- `assets/favicon.svg` — ícone do site
- `site.webmanifest` — manifest do PWA
- `pendencias.json` — pendências e suposições

## Como executar

Abra o arquivo `index.html` diretamente no navegador, ou rode um servidor estático local:

```bash
python3 -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Variáveis de ambiente

Nenhuma variável de ambiente necessária neste projeto estático.

## Observações de segurança

- Não há secrets, tokens ou credenciais no código.
- O conteúdo de contato foi mantido como informado pelo cliente.
- A página foi desenhada para evitar bibliotecas pesadas e excesso de JS.

## Pendências

Consulte `pendencias.json` para itens que ainda dependem de confirmação do cliente.

## Observação

Este é um site inicial e sem logo/identidade oficial. O texto e a estrutura foram criados com base no briefing disponível e em suposições registradas.
